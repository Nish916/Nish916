The iMedX HIM Companion Suite Modules

Code Workflow

Sophisticated coding workflow orchestration

Optimises the coding process through automated case allocation, priority-based queueing and progress tracking. It intelligently routes episodes for coding based on complexity and a coder’s expertise.

Manage. Prioritise. Perform.

  • Automatic, and configurable work queuing assignment by Speciality Area (Case Mix), Insurer, LOS, Priority, KPI due dates, etc
  • Centralised platform to manage HIM workloads, coding, and audit tasks
  • Audit and query management, with full task visibility
  • Performance dashboards to track productivity, time-to-code, inbound coding volume, revenue, etc.
  • When combined with other HCS modules, further insights are unlocked – with total revenue cycle performance in the one area.
Code Enhance

Live coding advice, auditing and DRG optimisation

Monitors coding accuracy, identifying potential DRG optimisation and clinical documentation improvement opportunities from the moment of coding.

Your smart second set of eyes.

  • Immediate coder feedback and education
  • Decreased days to cash through faster coding and audit cycles
  • Optimised DRG accuracy ensuring appropriate reimbursement and funding for care provided.
  • AI-assisted Clinical Documentation Query (CDQ) generation, based on specific insights on that episode from the findings identified by AI.
  • Integration with PAS and EMRs is pre-configured, and can be implemented rapidly.
Code Assist

A powerful alternative to traditional code finders

Designed for manual code assignment and automated grouping, combining expert decision logic, efficient coding prompts, and comprehensive DRG insights.

  • IHACPA Certified Grouper, integrates seamlessly with PAS and EMRs
  • Faster code search with curated guidance, speeding workflows up.
  • Embedded insights and scenario modelling.
  • Cost-effective DRG tool, giving a powerful alternative to legacy and outdated applications currently in the Australian market.
Code Accelerate

AI-assisted coding

Code Accelerate pre-populates clinical codes using advance AI and is designed to supplement the coding process to increase coding throughput, free up coders to focus on more complex cases and meet deadlines.

AI that understands your documentation.

  • Reads EMRs, scanned paper records, PDFs, and digital outputs
  • Auto-suggests ICD-10-AM and ACHI codes with accuracy indicators
  • PHI and PII Redaction engine that sits inside your network boundary for HIPAA-compliant privacy protection
  • Confidence scoring to guide human review.
Coding Assistant (Codie)

AI-enabled coding assistant

Codie is comprehensively trained and tested by HIM and coding experts. It provides real-time guidance, coding clarification, and decision support to enhance the coding process.

Codie isn’t just AI. He’s your companion for your coding workday!

  • Trained on ICD-10-AM, ACHI, DRG, ACS, State Based Advice, our proprietary knowledge and all updated regularly – keeping you always at the forefront of knowledge.
  • Purpose-built education for coders, auditors, clinicians, and execs
  • Supports facility-specific queries through custom knowledge bases
  • Handles advanced questions across Coding, funding, and operations
  • Incubated and tested by iMedX large Coding community for 12 months – it works!
  • Secure environment dedicated to only you, so you know your data is safe and secure – and never shared.
  • Secure, multi-agent AI that prompts users to provide more details, effectively guiding and navigating coders to the right answer in alignment with the coding classification and ACS.
