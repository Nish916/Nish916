Security & Privacy

Four principles underpin the information-security story.

The iMedX documentation page frames security around confidentiality, privacy, integrity and availability, with policies aligned to Australian health-record and privacy requirements.

Access

Confidentiality

Authorised users should access only the data needed to perform their role.

Control

Privacy

Personal and business data remains controlled within the contracted relationship and approved workflows.

Accuracy

Integrity

Information must remain accurate and complete through storage, processing and distribution.

Continuity

Availability

Authorised users should be able to access information when and where it is needed.

Clinical documentation FAQs

Answer the operational questions before the conversation.

The site now explains how creation choices, integration and delivery fit together.

Do clinicians have to use one document-creation method?

No. iMedX presents multiple options including medical transcription, clinician self-creation and AI-assisted documentation through InstaNote.

Can documentation connect to PAS or EMR systems?

Yes. The current iMedX site describes PAS/EMR integration and custom interface design for documentation workflows.

Which secure-message providers are supported?

The current ANZ site names HealthLink, Medical Objects and ReferralNet among supported Australian secure-message providers.

Is InstaNote a replacement for transcription?

It is presented as an additional AI-powered documentation option. The broader iMedX model retains multiple creation pathways so organisations can choose the workflow that fits each setting.
