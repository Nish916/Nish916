HIM Companion Suite

AI-Assisted Clinical Coding Solutions – Smarter Coding Starts Here.

Enhance your Health Information Management with the HIM Companion Suite – a powerful ecosystem of modular AI and human-enhanced tools designed to optimise clinical coding, auditing, and documentation accuracy.

Code Workflow Explore HCS →
01 / 05
01 · Manage. Prioritise. Perform.

Code Workflow

Sophisticated coding workflow orchestration: Optimises the coding process through automated case allocation, priority-based queueing and progress tracking. It intelligently routes episodes for coding based on complexity and a coder’s expertise.

02 · Your smart second set of eyes.

Code Enhance

Live coding advice, auditing and DRG optimisation: Monitors coding accuracy, identifying potential DRG optimisation and clinical documentation improvement opportunities from the moment of coding.

03 · Code-finding & grouping.

Code Assist

A powerful alternative to traditional code finders: Designed for manual code assignment and automated grouping, combining expert decision logic, efficient coding prompts, and comprehensive DRG insights.

04 · AI that understands your documentation.

Code Accelerate

AI-assisted coding: Code Accelerate pre-populates clinical codes using advance AI and is designed to supplement the coding process to increase coding throughput, free up coders to focus on more complex cases and meet deadlines.

05 · AI-enabled coding assistant.

Coding Assistant (Codie)

Codie is comprehensively trained and tested by HIM and coding experts. It provides real-time guidance, coding clarification, and decision support to enhance the coding process.
