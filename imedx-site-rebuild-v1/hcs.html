The HIM Companion Suite

Five modules. Different operational challenges. One connected HIM environment.

The suite is designed to work alongside existing products and clinical systems, with each module focused on a distinct HIM need.

Manage · Prioritise · Perform

Code Workflow

Orchestrates coding work through configurable queues, allocation and full task visibility.

  • Queue by case mix, insurer, LOS, priority and KPI dates
  • Centralise coding and audit workloads
  • Track productivity, time-to-code, volume and revenue
Assure

Code Enhance

Provides real-time coding feedback, auditing support and DRG optimisation opportunities.

  • Immediate coder feedback and education
  • Support faster coding and audit cycles
  • Surface documentation-query opportunities
  • Pre-configured PAS / EMR integration
Decide

Code Assist

A modern alternative to traditional code finders for manual code assignment and grouping.

  • IHACPA-certified grouper
  • Faster search with curated guidance
  • Embedded insights and scenario modelling
  • Designed as a cost-effective DRG tool
AI-assisted coding

Code Accelerate

Pre-populates suggested clinical codes so coders can focus on complex episodes and deadlines.

  • Reads EMRs, scanned records, PDFs and digital outputs
  • Suggests ICD-10-AM and ACHI codes with confidence indicators
  • Supports PHI / PII redaction inside the network boundary
  • Confidence scoring guides human review
Real-time guidance

Coding Assistant (Codie)

A secure AI-enabled coding companion trained and tested with HIM and coding expertise.

  • Supports ICD-10-AM, ACHI, DRG and ACS queries
  • Can use facility-specific knowledge bases
  • Handles coding, funding and operational questions
  • Designed to guide users toward the right answer

HCS questions buyers ask

Give stakeholders the answers before the demo.

Longer product pages feel complete when implementation, integration, scope and human oversight are answered directly.

Do we need to adopt every HCS module at once?

No. The current iMedX product positioning describes HCS as a modular suite; modules can address different operational challenges and can be adopted alongside existing products.

What types of records can Code Accelerate read?

iMedX states it can work with EMRs, scanned paper records, PDFs and digital outputs, then suggest ICD-10-AM and ACHI codes with confidence indicators.

Does HCS integrate with PAS or EMR systems?

Yes. The current HCS page describes PAS/EMR integration for relevant modules and positions the suite to work with existing healthcare systems.

Is Codie just a generic chatbot?

iMedX positions Codie as a coding-focused assistant trained/tested with HIM and coding expertise, covering coding, funding, operational and facility-specific questions.
