AI-Assisted Clinical Coding Solutions — Smarter Coding Starts Here.

Enhance your Health Information Management with the HIM Companion Suite — a modular ecosystem of AI and human-enhanced tools designed to optimise clinical coding, auditing and documentation accuracy.

The HIM Companion Suite Modules

One modular suite. Different operational challenges.

Built and refined around coder and HIS requirements, the suite can be adopted alongside current products and integrated into existing workflows.

Manage. Prioritise. Perform.

Code Workflow

Workflow orchestration for automated case allocation, priority-based queueing, progress tracking, workload management, audit/query management and performance dashboards.

Your smart second set of eyes.

Code Enhance

Live coding advice, auditing and DRG optimisation with immediate feedback, education, quality insight and AI-assisted clinical documentation query generation.

Code-finding & grouping

Code Assist

Manual code assignment and automated grouping with expert decision logic, curated prompts, DRG insights, scenario modelling and an IHACPA Certified Grouper.

AI-assisted coding

Code Accelerate

Reads EMRs, scanned records, PDFs and digital outputs; suggests ICD-10-AM and ACHI codes with accuracy indicators and confidence scoring for human review.

AI-enabled coding assistant

Codie

Real-time guidance, coding clarification and decision support across coding, funding and operations, trained and tested with HIM and coding expertise.
